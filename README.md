# ENRUTA 0.4 — PWA

Primera versión instalable como aplicación web progresiva (PWA), pensada para Android.

## Instalación
1. Publica esta carpeta en cualquier hosting estático HTTPS (por ejemplo GitHub Pages o Cloudflare Pages).
2. Abre la dirección desde Chrome en Android.
3. Pulsa «Instalar» cuando aparezca o usa Chrome → Añadir a pantalla de inicio.

No necesita dominio propio.

## Importante
Esta versión guarda los datos localmente en el teléfono y funciona offline una vez cargada. La sincronización automática con OneDrive/Dropbox y el empaquetado APK con Capacitor son pasos posteriores.
